# Font cục bộ

Be Vietnam Pro và Lexend, weight 400/500/600/700, sao chép nguyên tệp từ `HRM-chatgpt/prototype/assets/` ngày 16/11/2026 và đổi tên theo family/weight. `fonts.css` dùng `font-display: swap`. Không cần gọi Google Fonts khi xem component.

Heading dùng Lexend 500; body dùng Be Vietnam Pro 400. Font mã nguồn tiếp tục dùng fallback monospace nếu máy chưa có JetBrains Mono.

Bản quyền ghi trong metadata font: Be Vietnam Pro © 2021 The Be Vietnam Pro Project Authors; Lexend © 2019 The Lexend Project Authors. Kèm giấy phép SIL OFL lấy từ kho Google Fonts: [Be Vietnam Pro](OFL-BeVietnamPro.txt), [Lexend](OFL-Lexend.txt). Nguồn giấy phép: https://github.com/google/fonts/tree/main/ofl/bevietnampro và https://github.com/google/fonts/tree/main/ofl/lexend. Bản font gốc giữ nguyên; chỉ đổi tên tệp.
