# Modal

Hộp thoại cho nội dung cần xem hoặc nhập mà không rời màn: tiêu đề, nút đóng, thân và chân có nút. Rộng 440px (mặc định) hoặc 880px (`wf-dialog--lg`, ví dụ bảng so sánh, xác minh hồ sơ).

## Quy tắc
- Đóng bằng nút ×, phím Esc, hoặc bấm ra ngoài khi chưa nhập gì.
- Không mở hộp thoại chồng lên hộp thoại.
- Thao tác khó hoàn tác dùng ConfirmDialog thay vì Modal.
