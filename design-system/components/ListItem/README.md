# ListItem

Một dòng trong danh sách việc làm, hồ sơ, đơn: logo hoặc avatar 56px, tiêu đề đậm 16px, dòng thông tin phụ; rê chuột đổi nền xám nhẹ và tiêu đề đỏ đậm.

## Người dùng cung cấp
Tiêu đề, 2–4 thông tin phụ kèm icon, một nhãn trạng thái bên phải. Dòng đang chọn thêm `wf-item--selected`.

## Quy tắc
Cả dòng bấm được để mở chi tiết; nút thao tác riêng trong dòng dùng `wf-btn--sm`.
