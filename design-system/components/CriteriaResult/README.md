# CriteriaResult

Kết quả đánh giá theo từng tiêu chí với **3 trạng thái tách biệt**: Đạt, Chưa đạt, Chưa đủ bằng chứng. "Chưa đủ bằng chứng" dùng nhãn viền nét đứt (`wf-badge--unknown`), không dùng màu đỏ.

## Dùng khi
Kết quả bài đánh giá (6.5), điều kiện hoàn tất onboarding, kết quả năng lực theo kỳ (6.8).

## Quy tắc
Mỗi tiêu chí ghi căn cứ (điểm, phiên bản đề, nguồn). Tiêu chí chưa đạt kèm gợi ý học bổ sung. Hết lượt làm lại thì ghi người phụ trách tiếp theo.
