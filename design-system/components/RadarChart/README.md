# RadarChart

So sánh hồ sơ năng lực của một nhóm với **chuẩn vai trò** trên 5–8 nhóm năng lực (6.9, US-6.9.2). Nhóm đang xem: vùng `chart-1` mờ, viền 2px; chuẩn: đường nét đứt `ink-subtle`, không tô.

## Quy tắc
- Tối đa 2 đường (nhóm và chuẩn). So sánh nhiều nhóm thì dùng nhiều radar nhỏ cạnh nhau hoặc BarChart.
- Rê chuột lên điểm thì hiện giá trị nhóm và chuẩn.
- Luôn có chế độ Bảng, vì radar khó đọc giá trị chính xác.
