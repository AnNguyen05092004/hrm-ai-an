# ProgressBar

Thanh tiến độ có nhãn và con số: tiến độ onboarding, khóa học, tỷ lệ hoàn thành kỳ đánh giá. Mặc định `primary`; `--success` khi đã gần xong hoặc đạt mục tiêu; `--warning` khi chậm so với hạn.

## Quy tắc
Luôn ghi số (phần trăm hoặc x/y) bên cạnh; không dùng thanh tiến độ khi không biết tổng.
