# BarChart

Biểu đồ cột ngang so sánh một chỉ số giữa các đơn vị (6.9: so sánh giữa các đơn vị). Cột của đơn vị đang xem dùng `chart-1`, các đơn vị khác `chart-2`; đường nét đứt là mục tiêu.

## Quy tắc
- Cột ngang khi tên dài (tên đơn vị); sắp từ cao xuống thấp.
- Ghi giá trị ở cuối mỗi cột; trục bắt đầu từ 0.
- Tối đa 12 cột; nhiều hơn thì cho chọn phạm vi nhỏ hơn.
- So sánh nhiều kỳ theo thời gian dùng biểu đồ đường, không dùng cột.
