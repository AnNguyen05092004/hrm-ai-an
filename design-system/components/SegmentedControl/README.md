# SegmentedControl

Chọn một trong 2–4 lựa chọn ngắn đặt cạnh nhau: định dạng nội dung (Khóa học / Tình huống), kiểu xem (Biểu đồ / Bảng). Lựa chọn dài hoặc nhiều hơn 4 dùng Radio (`wf-radio`) hoặc ô chọn.

## Quy tắc
Mỗi biểu đồ có lựa chọn "Bảng" để xem số liệu dạng bảng (yêu cầu tiếp cận cho người không phân biệt màu).
